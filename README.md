# NASA Projects

Four projects built on NASA open data. Each folder is self-contained.

| # | Project | Stack | Status |
|---|---------|-------|--------|
| 1 | [asteroid-tracker](asteroid-tracker) | Python, NeoWs API, pandas, matplotlib, Streamlit | MVP |
| 2 | mars-data-analysis | Python, pandas, statistics | Planned |
| 3 | nasa-image-explorer | JavaScript, HTML/CSS, NASA GIBS | Planned |
| 4 | astro-ml-classifier | scikit-learn | Planned |

## API key
Get a free key at https://api.nasa.gov and set `NASA_API_KEY`. Without one, the code falls back to `DEMO_KEY` (heavily rate limited).
